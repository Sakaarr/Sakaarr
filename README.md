## `whoami`

I design and harden backend systems — async services, third-party API integrations, and the unglamorous plumbing that keeps them reliable under real-world failure conditions: rate limits, token rotation races, silent errors, and APIs that lie about their own status codes.

I like the debugging work as much as the building work. Tracing a bug back through three layers of "helpful" abstraction to the one line that swallowed an exception is, to me, a genuinely good time.

## What I actually spend my time on

- **Integration engineering** — connecting systems that were never designed to talk to each other, and making that connection survive contact with production traffic
- **Auth & token systems** — OAuth flows, refresh rotation, the concurrency bugs that only show up under load
- **Debugging over guessing** — I'd rather spend an hour finding the root cause than ten minutes silencing the symptom
- **Multi-tenant SaaS architecture** — building platforms meant to serve many organizations from one well-structured codebase
